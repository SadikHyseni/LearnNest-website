# 📚 LearnNest — After-School Lessons Website

LearnNest is an interactive web application designed to help parents and students discover and book after-school lessons. The website provides a simple and user-friendly experience for browsing activities, managing a shopping cart, and completing bookings.

🌐 **[View Live Website](https://sadikhyseni.github.io/LearnNest-website/)**

## ✨ Features

- 🔍 **Search Lessons** — Find lessons and activities easily.
- 📊 **Sort Lessons** — Organize available lessons based on different criteria.
- 🛒 **Shopping Cart** — Add and remove lessons from the cart.
- 📦 **Availability Tracking** — View available spaces for lessons.
- 💳 **Checkout Form** — Enter customer information to complete a booking.
- 🎨 **Responsive Interface** — A clean and accessible website layout.

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and layout
- **JavaScript** — Application logic and interactivity
- **Vue.js** — Reactive user interface and dynamic content

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/SadikHyseni/LearnNest-website.git
```

### 2. Navigate to the Project

```bash
cd LearnNest-website
```

### 3. Run the Website

Open `index.html` in your web browser.

You can also use the Live Server extension in Visual Studio Code for local development.

## 🛒 How It Works

1. **Browse Lessons:** Explore the available after-school activities.
2. **Search and Sort:** Find lessons based on your preferences.
3. **Add to Cart:** Select lessons you want to book.
4. **Manage Your Cart:** Review or remove selected lessons.
5. **Checkout:** Enter the required customer information and complete the booking process.
